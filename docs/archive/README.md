# Documentation archive

Historical planning and review documents from the design phases of the WMIT
system — baselines, implementation plans, gap analyses, and architecture
reviews that preceded the implemented hosted server. Archived August 2026:
they are superseded by the working system and its living documentation, and
kept only as a record of how the architecture was decided.

For current architecture, start at [../architecture.md](../architecture.md);
for daily operation, the root [../](../) documentation index.
